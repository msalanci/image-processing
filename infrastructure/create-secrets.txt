The values of the two secrets. terraform apply creates both secrets empty (secrets.tf); set
each value once after the first apply. Until then the review editor refuses every request and
the committer cannot reach GitHub.

### Review editor username and password (HTTP Basic Auth)

#### Create them and store them in the secret
U=$(openssl rand -hex 16)
P=$(openssl rand -base64 32)
aws secretsmanager put-secret-value \
  --secret-id buildercards/review-basic-auth \
  --secret-string "{\"username\":\"$U\",\"password\":\"$P\"}" \
  --region eu-central-1
echo "username: $U"; echo "password: $P"


### Fine-grained personal access token for GitHub

1. Create a fine-grained personal access token on https://github.com/settings/personal-access-tokens/new
for the site repository only, with these repository permissions:
Contents - Read and write    (the committer commits the card's .md and .png straight to the publish branch, master by default)
Metadata - Read-only
Nothing else is needed: the committer commits directly and opens no pull requests.

2. Store it in the secret
aws secretsmanager put-secret-value \
  --secret-id buildercards/github-pat \
  --secret-string '<current_token>' \
  --region eu-central-1
